# Milestone 4 Gate — Passed

Date: 2026-07-19

## Delivered

- Manifest-first remote open; the application receives a stream before blob chunks are downloaded.
- Independent encrypted chunks scheduled across multiple iroh-blobs provider connections.
- Round-robin provider selection, retry/failover, bounded sequential prefetch, three priority classes, and cancellation of an obsolete pending read on seek.
- One bounded decrypted RAM chunk; remotely fetched manifests/chunks remain encrypted in the iroh-blobs filesystem store and are reused as persistent cache/pinned data.
- Live provider-attempt and verified-fetch counters.
- Provider-independent `BlobStream` remains `AsyncRead + AsyncSeek`; upstream native fan-in can replace the internal connection pool without changing the public stream contract.
