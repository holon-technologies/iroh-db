# Milestone 4 Gate — Passed

Date: 2026-07-19

## Delivered

- Manifest-first remote open; the application receives a stream before blob chunks are downloaded.
- Four-MiB independently encrypted chunks scheduled concurrently across multiple iroh-blobs provider connections while iroh-blobs retains transport and hash verification.
- Process-shared bounded transfer admission with deterministic 4:2:1 high/normal/low fairness and per-provider concurrency caps.
- Per-stream provider exploration and scoring from EWMA verified latency and throughput, in-flight load, recent errors, and bounded exponential backoff with deterministic jitter.
- One bounded hedge for stalled high-priority foreground objects, adaptive 50–500 ms hedge delay, retry/failover, and cancellation-safe capacity guards.
- A moving bounded sequential prefetch window one priority below foreground work; seeking/dropping aborts obsolete work, cached-chunk reads restart the window after seek, and overlapping requests for one hash are coalesced with foreground priority promotion.
- Authenticated endpoint IDs are deduplicated before provider slots are assigned, so duplicate addresses cannot bypass concurrency limits or provide false hedge diversity.
- One bounded decrypted RAM chunk; remotely fetched manifests/chunks remain encrypted in the iroh-blobs filesystem store and are reused as persistent cache/pinned data.
- Live attempts, verified objects/bytes, cache hits, retries, hedges, and low-cardinality per-provider quality snapshots.
- Provider-independent `BlobStream` remains `AsyncRead + AsyncSeek`; upstream native fan-in can replace the internal connection pool without changing the public stream contract.

## Gate Evidence

`blob_multisource::lazy_stream_seeks_by_chunk_and_fails_over_between_providers`
fetched only the manifest before return, learned from the first successful
provider, lost that provider mid-stream, retried the non-adjacent tail through
the remaining provider, and returned the exact authenticated bytes.
`prefetch_window_moves_after_seek_and_reports_provider_quality` proves that a
two-chunk window moves to the new seek position and reports verified bytes and
provider quality.

Deterministic scheduler tests prove 4:2:1 admission without starvation,
cancellation-safe waiter cleanup, initial provider exploration, measured
completion-time ranking, per-provider concurrency, bounded jittered cooldown,
and adaptive hedge delay. A delayed real iroh provider test proves a
high-priority hedge completes through the second provider and cancels the
stalled attempt.

Existing corruption and range-accounting tests also pass:

- ciphertext hash or AEAD corruption fails before plaintext;
- local reads and seeks load only intersecting chunks;
- streaming import remains bounded and preserves media metadata.
