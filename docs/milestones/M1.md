# Milestone 1 Gate: Embedded Database

Status: Passed
Date: 2026-07-19
Toolchain: `rustc 1.91.0 (f8297e351 2025-10-28)`

## Delivered

- Ten-crate Rust workspace with unsafe code forbidden and a Rust 1.91 MSRV.
- Fixed domain-separated IDs, strict canonical schemas, records, commits, and golden vectors.
- Deterministic `Lww`, `OrSet`, `GrowOnlySet`, `PnCounter`, `MultiValue`, `Immutable`, and `OrderedList` implementations with merge-law tests.
- `#[derive(IrohRecord)]` with compile-pass and compile-fail contracts.
- Owner-only local credentials, signed encrypted commits, one default private domain, one commit per atomic local transaction, and redb materializations/indexes.
- Primary-key scans, indexed equality, decoded-value ranges and ordering, limits, authenticated opaque cursors, and initial-plus-change bounded subscriptions.
- iroh-blobs-backed immutable storage, independently encrypted chunks/manifests, incremental import, immediate lazy reads, seek/range behavior, and corruption rejection before plaintext release.
- Signed encrypted snapshots, atomic rejection behavior, full immutable-log rebuild, state-root equivalence, reopen, idempotency, fault rollback, and blob-first commit-orphan detection.
- A compiling and running public music example and embedded-operation documentation.

## Scope Boundary

Milestone 1 opens no endpoint and performs no peer synchronization. The iroh-blobs filesystem actor is local storage only. Multi-domain membership, capability delegation, invitations, epoch rotation, gossip, ALPN synchronization, multi-provider scheduling, operational CLI workflows, and production hardening remain closed until their later milestones.

## Decision

The Milestone 1 acceptance gate passes. The user granted standing approval, so Milestone 2 may begin.
