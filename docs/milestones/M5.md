The complete workspace gate passes and the extended soak is intentionally
ignored unless explicitly selected. The accelerated real-network churn test
performs repeated offline writes and reordered pair reconnections across three
peers, then proves identical state roots and complete records. Backup/restore
proves state-root equality and rejects a modified archive before creating a
destination. The full cargo-deny policy accepts exceptional licenses only
through reviewed package-scoped entries and accepts only three reasoned
informational upstream advisories; every unlisted finding remains fatal. The
optimized encrypted local-stream benchmark measured 232.7 MiB/s on this host.

Fuzz qualification replays twenty checked-in malformed, boundary, and
structure-aware valid seeds through the same five shared harnesses used by
libFuzzer. Structured prefixes convert mutable seed suffixes into valid
canonical objects, including signed inputs that blind byte mutation is
unlikely to discover. The scheduled/manual workflow runs each target
independently with a ten-minute default mutation budget, rejects durations
outside 1 through 18,000 seconds, and retains both the evolved corpus and crash
evidence. A bounded local smoke run of every target is required for this
checkpoint; it is not represented as a long-running fuzz campaign.

Cargo verifies the workspace source through strict Clippy, tests, and docs.
The package verifier assembles every crate archive, extracts its normalized
manifest and packaged files, patches internal dependencies to the other
extracted archives, and compiles every packaged crate with all targets. The
publish dry-run then uses `--no-verify` because Cargo's built-in verifier would
instead resolve mutually unpublished internal packages from the public
registry. The dry-run performs Cargo's client-side pre-upload checks but does
not exercise registry-server validation; actual publication must preserve
Cargo's dependency order.
