# Milestone 5: Production Hardening Plan

## Goal

Make failures detectable and recovery non-destructive. Ship live verification, typed shadow rebuild, index repair, checksummed closed-store backup/restore, an operational CLI, compatibility policy, fuzz targets, deterministic reconnect churn, an opt-in extended soak, strict CI/MSRV gates, and release checks.

## Gate

- Verification checks immutable hashes, canonical decoding, signatures, epoch decryption, dependencies, orphan objects, and derived rebuild equality.
- Repair builds replacement state before one atomic metadata swap.
- Restore verifies every checksum and unsafe path before creating the destination; it never overwrites an existing database and restores key permissions.
- CLI exposes verify, repair-indexes, backup, and restore.
- Protocol/format golden tests, malformed corpora, CRDT properties, reconnect churn, and all prior milestone tests pass under the MSRV.
- Extended soak and fuzz commands are reproducible in CI/nightly environments; release policy records that their duration is evidence, not a unit-test substitute.
