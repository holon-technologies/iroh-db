# Milestone 4: Blob Performance Plan

## Goal

Keep `BlobStream` provider-independent while adding manifest-first startup, chunk-level multi-provider fan-in, bounded prefetch, priority classes, retry/failover, encrypted persistent cache reuse, RAM chunk caching, live transfer counters, and a repeatable throughput benchmark. iroh-blobs continues to own transport and hash verification.

## Gate

- Opening remotely transfers only the manifest before returning.
- Reads and seeks fetch only intersecting chunks plus explicitly bounded prefetch.
- Provider selection rotates by chunk; provider loss retries another source without returning unauthenticated plaintext.
- Corrupt hashes or AEAD tags fail before plaintext.
- Cache storage is ciphertext; only the bounded current RAM chunk is plaintext.
- The benchmark and integration suite remain stable under strict workspace linting.
